# Life Planner

Maxi's daily planning hub — Today, Calendar, Goals (pillars → goals → phases → steps), Journal & reviews, Habits, Inbox, Vision.

Live app: https://maxijpeak111.github.io/life-planner/ (GitHub Pages: branch `main`, folder `/docs`).

All data is saved on the phone only (localStorage). Use **More → Settings & backup → Export backup** regularly.
